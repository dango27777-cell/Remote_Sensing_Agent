# Remote_Sensing_Agent

An experimental AI agent prompt for satellite imagery processing workflows.

## Why I created this

While developing my GeoAI projects, I found that general-purpose AI assistants often struggle with remote sensing image processing problems.

Many answers are technically plausible but miss important details such as:

- sensor-specific band definitions
- raster metadata
- pan-sharpening workflows
- radiometric processing
- GIS software behavior differences
- visualization vs data problems

To improve this, I summarized my practical experience in satellite imagery processing and created this simple Remote Sensing Processing Agent.

This project is not a complete software package. It is a knowledge-enhanced AI agent prompt designed to help GIS and remote sensing users work more effectively with AI assistants.

---

## What can it help with?

The agent focuses on:

### Satellite imagery troubleshooting

Examples:

- Why does my image become purple/yellow after processing?
- Why do different tiles have different colors?
- Is this a band order problem or a visualization problem?

### Raster workflow design

Examples:

- MSS + PAN processing workflow
- Pan-sharpening troubleshooting
- Mosaic Dataset workflow
- Color balancing strategy

### GIS automation

Examples:

- GDAL workflows
- ArcPy scripts
- Raster validation scripts
- Quality control procedures
