Example: Incorrect Colors After Pan-sharpening
User Problem
Some tiles look normal, while others appear yellow or missing colors after pan-sharpening.
Agent Reasoning
Possible causes:
Different band order between outputs
Incorrect RGB interpretation
Metadata inconsistency
Mosaic processing issues
Recommended diagnosis:
Check raster band descriptions
Compare original MSS bands
Validate pixel values
Avoid changing histogram before confirming band order
Key Lesson
A color problem is not always a color problem.
It may be a data structure problem.
